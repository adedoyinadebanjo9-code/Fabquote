▸ Pricing assumptions (locked)

Fixed retail pricing: customer prices are deliberately kept competitive. Material, machine, setup and margin rates are locked in the application and can only be changed in the source code.

Import formats: SVG, DXF and PDF/AI (PDF-compatible) vector files auto-detect cut vs. engrave — colour a path red for cutting and any other colour (typically black) for engraving; files with no red are priced entirely as cut. PNG/JPG raster images are traced for an engrave-only area estimate and always need human review before production. Native CorelDraw (.cdr) and non-PDF-compatible .ai files can't be parsed in-browser — export as PDF, SVG or DXF.
Nesting method: when your file's geometry can be nested, FabQuote runs a real geometry-aware nesting pass (not a bounding-box guess) to estimate sheet utilization. If nesting isn't possible for your file (e.g. very complex geometry, low quantity, or the engine times out) it falls back to a conservative rectangular-packing estimate instead. The live quote readout below shows exactly which method was used for this quote — check it before assuming the price reflects optimal layout.
Best accuracy: use Bambu Studio / OrcaSlicer first. Enter the slicer filament weight and print time below; FabQuote will price those confirmed values instead of guessing.

FDM note: without a slicer, this is still an estimate. The engine now uses shell volume + infill volume + flow/layer timing instead of treating infill as a simple percentage of the solid model. For customer-final pricing, confirm against Bambu Studio/your slicer.
Best accuracy: if your resin slicer (Chitubox, Lychee, PrusaSlicer) reports resin volume and print time, enter them below to price the confirmed values instead of the geometry estimate. Uploading an SL1/SL1S file auto-fills layer height, exposure and height; other native resin formats (CTB, Photon, PWMX, GOO…) are recognized but need manual entry.
